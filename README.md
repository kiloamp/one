# A320 Type Rating Portal

A static dashboard prototype for an A320 type rating student portal.

The page includes simulator schedule, class schedule, training phase progress,
instructor comments, airline readiness metrics, and passed or failed exam gates.

## Structure

- `index.html` contains the page shell and static compliance panels.
- `styles.css` contains the visual system and responsive layout.
- `lesson-data.js` contains the structured FFS lesson data used by the UI.
- `lesson-plan.md` is the readable source lesson plan.
- `app.js` renders the dashboard, timeline, setup block, and debrief drawer.
